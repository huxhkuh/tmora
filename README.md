# תמורה · מעקב זמן עבודה

אפליקציה אישית בעברית ובאנגלית למעקב זמן עבודה, לקוחות ופרויקטים. עם חלון צף זעיר שנשאר מעל החלונות, דוחות ושמירה מקומית במחשב שלך.

קוד הפרויקט זמין ברישיון [MIT](LICENSE). רכיבי צד שלישי נשארים תחת רישיונותיהם המקוריים; ראו [הודעות רישוי](THIRD_PARTY_NOTICES.txt).

[עמוד ההורדה של תמורה](https://huxhkuh.github.io/tmora/)

## התקנה ב־Windows

### [⬇ הורדת המתקין הקטן של תמורה](https://github.com/huxhkuh/tmora/releases/latest/download/Temura-Install.exe)

1. מורידים ופותחים את **Temura-Install.exe** — קובץ קטן של כ־38 KB.
2. לוחצים **התקנת תמורה**. המתקין מוריד את הגרסה העדכנית מ־GitHub, בודק את הקובץ ומתקין בחשבון Windows הנוכחי, ללא בקשת הרשאות מנהל.
3. לוחצים **פתיחת תמורה**. קיצור דרך נוסף לשולחן העבודה ולתפריט ההתחלה.

נדרש Windows 10/11 עם מעבד x64 וחיבור לאינטרנט להתקנה. לאחר ההתקנה אפשר לעבוד ללא חיבור. אין צורך ב־Node.js, בחשבון משתמש באפליקציה או בשירות בתשלום.

**[כל הגרסאות וההורדות](https://github.com/huxhkuh/tmora/releases/latest)** — שם זמינים גם המתקין המלא להתקנה ללא חיבור (`Setup.exe`), גרסה ללא התקנה (`Portable.exe`) וקובץ בדיקות תקינות (`SHA256SUMS.txt`).

הקבצים עדיין אינם חתומים בתעודת מפרסם, ולכן Windows עשוי להציג אזהרת מפרסם לא מזוהה. אין צורך לשנות את הגדרות האבטחה.

**[Code signing policy — מדיניות חתימה](CODE_SIGNING.md)**: הבקשה למסלול החינמי של SignPath Foundation הוגשה ב־8 בספטמבר 2026 ונקלטה; היא ממתינה לבדיקה, וטרם התקבל אישור לחתימה. **[מדיניות פרטיות / Privacy policy](PRIVACY.md)**.

### עדכון מתוך האפליקציה

**גרסה 1.5.1** מתקנת שרתים שמתעלמים מבקשות הורדה חלקית: עוברים מיד להורדה מלאה מאומתת. אם עדכון בגרסה ישנה נשאר על 100%, בטלו וסגרו את האפליקציה והפעילו פעם אחת את המתקין הקטן החדש. הנתונים נשמרים.

מגרסה **1.4.0**, פותחים **גיבוי והגדרות → תמורה מתחדשת → בדיקת עדכונים**. כשיש גרסה חדשה, לוחצים **הורדת העדכון**; אפשר להמשיך לעבוד ולבטל את ההורדה. בסיום בוחרים **התקנה והפעלה מחדש** ומאשרים. סגירה רגילה של האפליקציה אינה מתקינה עדכון.

המנגנון מוריד את החלקים שהשתנו ומרכיב מהם קובץ התקנה שנבדק באמצעות SHA-512. החיסכון תלוי בהיקף השינוי ובזמינות מטמון המתקין הקודם; אם ההורדה החלקית אינה אפשרית, הוא מוריד את הקובץ המלא. המטמון נשמר ב־`%LOCALAPPDATA%\bou-time-updater`; ניקויו עשוי לחייב הורדה מלאה בפעם הבאה.

**למעבר מגרסה 1.3.0 ומטה יש להפעיל פעם נוספת את המתקין הקטן**, אחרי סגירת תמורה. לאחר מכן העדכונים זמינים בתוך האפליקציה. הגרסה הניידת (`Portable`) אינה מתעדכנת מתוך עצמה. בזמן הפעלה מחדש הנתונים נשמרים וטיימר פעיל ממשיך לפי חותמת הזמן השמורה; סיימו עריכת טקסט לפני ההתקנה.

## מה יש בפנים

גרסה **1.5.3** מוסיפה **מחיקת לקוח ופרויקט** באמצעות סמל הפח ברשימה. האישור מציג כמה פרויקטים, משימות ורישומי זמן יימחקו ומחייב הקלדת השם. מחיקת לקוח כוללת גם את הפרויקטים שלו שבארכיון; מחיקת פרויקט כוללת את משימותיו ושעותיו. טיימר פעיל או מושהה חייב להיעצר ולהישמר תחילה. לשמירת ההיסטוריה אפשר להשתמש בארכיון. מומלץ לייצא גיבוי לפני מחיקה; ייבוא גיבוי ישן יכול להחזיר פריטים שנמחקו.

גרסה **1.5.2** מוסיפה **תצוגה בהירה וכהה** דרך **גיבוי והגדרות → שפה ומראה → תצוגה**. הבחירה נשמרת וחלה גם על הצג הצף ומצב המיקוד, עם כל ארבע ערכות הצבעים.

גרסה **1.5.0** משלימה את המעבר למאגר `tmora`, מוסיפה **אנגלית** וארבע **ערכות צבעים**. בוחרים דרך **גיבוי והגדרות → שפה ומראה**. ההעדפות חלות גם על הצג הצף ונשמרות במכשיר, בנפרד מגיבוי נתוני העבודה. שעון ישראל ומטבע ₪ נשארים ללא שינוי. [הוספת תרגומים וערכות צבעים](docs/LOCALIZATION.md).

גרסה **1.4.1** מוסיפה הקשחת Windows, בדיקת קובץ עדכון מחדש לפני התקנה והגנות נוספות לייבוא גיבויים ולייצוא CSV. פירוט ההגנות והמגבלות נמצא ב־[SECURITY.md](SECURITY.md). משתמשי 1.4.0 יכולים לקבל אותה דרך **גיבוי והגדרות → בדיקת עדכונים**.

- לקוחות ופרויקטים עם צבע, תיאור, ארכיון, תעריף שעתי או מחיר כולל ויעד שעות.
- **צ׳קליסט לכל פרויקט** — הוספת משימות, סימון השלמה, עריכה ומחיקה עם אישור; כולל סיכום התקדמות ושמירה בגיבוי.
- **עדכונים פנימיים ב־Windows** — בדיקה והורדה מתוך ההגדרות, הורדה חלקית כשאפשר והתקנה באישור בלבד.
- טיימר עם השהיה והמשך, שמירה לפי חותמות זמן והתאוששות אחרי סגירה או שינה.
- **צג צף זעיר** עם פרויקטים זה מתחת לזה. לחיצה על פרויקט שומרת את הזמן הקודם ומתחילה את הבא.
- רישום ידני, עריכה, התראה על חפיפות ותמיכה בעבודה שחוצה חצות.
- סיכומי יום ושבוע, דוחות לפי לקוח ופרויקט וייצוא CSV בעברית לאקסל.
- גיבוי מלא וייבוא עם מניעת כפילויות. נתוני הדגמה מופרדים מהנתונים האישיים.
- עברית, RTL, אזור הזמן של ישראל ומצב מיקוד. **Alt+P** פותח צג צף; **Alt+F** פותח מצב מיקוד.

## תקציבי שעות ודוחות לקוח

נוספו סיווג זמן לחיוב/פנימי/טרם סווג, תקציב שעות עם יתרה וחריגה, ספי התראה ודוח לקוח בעברית עם תעריפים היסטוריים או שעות בלבד. הדוח זמין בתצוגה מקדימה, CSV, HTML עצמאי והדפסה ל־PDF.

[מדריך שימוש וכללי החישוב והשדרוג](docs/BILLING.md). רישומים ישנים נשארים עם זמניהם ותעריפיהם המקוריים, ומחכים לסיווג מפורש לפני הכללה בדוח לקוח.

## איפה נשמר המידע ואיך מגבים

לניהול הצ׳קליסט: פותחים **פרויקטים → משימות** בכרטיס הפרויקט. המשימות נפרדות לכל פרויקט, נשארות זמינות בארכיון ואינן מפעילות או עוצרות מדידת זמן. אפשר לסמן משימה שהושלמה ולהחזיר אותה למצב פתוח.

![צ׳קליסט נפרד לכל פרויקט — נתוני דוגמה](docs/images/checklist.png)

ב־Windows הנתונים נשמרים מקומית ב־IndexedDB תחת `%APPDATA%\BouTime`, בנפרד לכל משתמש Windows. המתקין מתקין את התוכנה בלבד; הוא אינו מעלה את הלקוחות, הפרויקטים או השעות ל־GitHub. אין סנכרון ענן.

בתוך האפליקציה: **גיבוי והגדרות → ייצוא גיבוי מלא**. שמרו את קובץ ה־JSON גם במקום נוסף. לשחזור: **בחירת קובץ גיבוי לשחזור → ייבוא ומיזוג**. התקנה חוזרת והסרת התוכנה משאירות את הנתונים האישיים במקומם.

החל מגרסה 1.3.0 גיבוי מלא כולל גם משימות ומצב השלמה. גיבויים ישנים ללא משימות נתמכים. בייבוא חוזר, משימה עם מזהה שכבר קיים שומרת את הנוסח ומצב ההשלמה המקומיים. ייבוא של גיבוי ישן יכול להחזיר משימות שנמחקו מאז; הייבוא ממזג רשומות ואינו מחליף את כל הנתונים. לשחזור משימות יש להשתמש בגרסה 1.3.0 ומעלה.

גרסת הדפדפן שומרת נתונים באותו דפדפן ומכשיר בלבד. מעבר מהדפדפן לאפליקציית Windows דורש ייצוא גיבוי וייבוא שלו. מומלץ לעצור ולשמור מדידה לפני המעבר.
